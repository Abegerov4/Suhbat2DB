## Переходы

Все переходы: *On click → Navigate to*, анимация *Dissolve* 200 мс.

| Откуда | Кликабельная зона | Куда |
|---|---|---|
| 01 Вход | кнопка «Войти» | 02 Обзор |
| 02 Обзор | «Новый диалог» в шапке | 04 Новый диалог |
| 04 Новый диалог | пример «Покажи продажи за прошлый квартал» или поле вопроса | 05 Ход агента |
| 05 Ход агента | автоматически через 1,5 с | 06 Уточнение |
| 06 Уточнение | кнопка «Продолжить» | 07 Ответ — график |
| 07–10 Ответ | вкладки «График», «Таблица», «SQL», «Проверка» | соответствующий экран |
| 07 Ответ — график | поле вопроса | 11 Отказ |
| 02, 03, 04, 07–11 | меню слева: «Обзор», «Новый диалог», «Источники данных» | 02, 04, 03 |

Экран 12 (телефон) и экран 13 (тёмная тема) показываются отдельно: 12 — стартовая точка потока «С6. Телефон», 13 открывается со страницы «Сценарии».

## Что сделать автору

1. Открыть файл и в правом верхнем углу нажать **▶ Present**. Выбрать поток «С3. Вопрос с уточнением» и пройти его: Войти → Новый диалог → пример вопроса → (ожидание) → Продолжить → вкладки → поле вопроса → отказ → меню.
2. Если какой-то переход ведёт не туда, в режиме **Prototype** выделить слой «Хотспот: …» в нужном фрейме и поправить цель перехода справа.
3. **Share → Anyone with the link → can view**, чтобы ссылки из README открывались у руководителя и комиссии без приглашения.
4. Сообщить, что всё готово: после этого DIP-17 закрывается и ставится тег `pre-defense-1` (DIP-18).

## Как переснять экраны

Нужен запущенный стек (`make up`) и ключ OpenAI; сценарий с уточнением стоит около $0,02. Скрипт Playwright входит под демо-аналитиком `demo.analyst@suhbat2db.kz`, для экрана источников под администратором из `.env`, и сохраняет 13 снимков в `screens/` в разрешении 2×. После пересъёмки снимки в Figma заменяются через заливку слоёв «Снимок» в каждом фрейме.

## Критерий приёмки DIP-17

Сценарий «вопрос → уточнение → ответ» проходится по переходам от экрана входа до вкладок ответа; ссылка на прототип открывается без входа в Figma; ссылка добавлена в README и `docs/prototype/README.md`.
