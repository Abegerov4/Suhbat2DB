## Как собрать прототип в Figma

1. Создать файл, страницу Prototype. Фреймы *Desktop* 1440 × 900 и *iPhone 14* 390 × 844.
2. Перетащить скриншоты в фреймы (снимки сделаны в 2×, при вставке масштабировать до 1440 по ширине).
3. В режиме Prototype поверх кнопок нарисовать прозрачные прямоугольники-«хотспоты» и связать переходами *On click → Navigate to*:
   - 01 «Войти» → 02;
   - 02 «Новый диалог» → 04;
   - 04 поле вопроса → 05 (*After delay* 1500 мс) → 06;
   - 06 «Продолжить» → 07;
   - 07 вкладки → 08, 09, 10;
   - 07 поле вопроса → 11;
   - 02 «Источники данных» → 03.
4. Стартовым экраном потока сделать 01, поток назвать «С3. Вопрос с уточнением».
5. *Share → Anyone with the link can view*, ссылку вставить в этот файл и в [README](../../README.md).
