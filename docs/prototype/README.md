## Как устроен прототип

Страница **Prototype** содержит 13 фреймов (12 × 1440 × 900 и 1 × 390 × 844) с кликабельными зонами поверх снимков. Основной поток «С3. Вопрос с уточнением» начинается с экрана 01: вход → обзор → новый диалог → вопрос → ход агента (переход через 1,5 с) → уточнение → ответ; на экранах ответа работают вкладки «График», «Таблица», «SQL», «Проверка», поле вопроса ведёт к экрану отказа, меню слева доступно на всех экранах приложения. Второй поток «С6. Телефон» начинается с экрана 12.

Страница **Сценарии** группирует экраны по сценариям С1–С6 со связанными требованиями.
